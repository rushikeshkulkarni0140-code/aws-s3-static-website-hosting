## 📌 Project Overview

I designed and deployed my personal cloud portfolio website using **Amazon Web Services (AWS) S3 Static Website Hosting**.

This project demonstrates my practical understanding of AWS S3, static website hosting, bucket policies, public access configuration, and cloud-based website deployment.

## 🛠️ Tech Stack

- Amazon Web Services (AWS)
- Amazon S3
- HTML
- CSS
- Static Website Hosting
- AWS Bucket Policy

## 🚀 Implementation Steps

1. Created an S3 bucket named `rushikesh-cloud-portfolio-2026`.
2. Uploaded website files, including HTML, CSS, and images.
3. Enabled Static Website Hosting in the S3 bucket properties.
4. Configured public access settings.
5. Created and applied an S3 bucket policy to allow public read access.
6. Troubleshot and resolved the **403 Forbidden** error caused by restricted object access.
7. Verified the deployment using the S3 static website endpoint.
